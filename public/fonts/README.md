# Type library

Self-hosted OFL print faces for Carson, plus Studio OS Google Fonts and Fontshare loaded on demand. Regenerated by:

```bash
npm run import-fonts
```

Grouped in the picker as Condensed, Display, Grotesk, Serif, Slab, and Typewriter. Search the menu to jump to Inter, Satoshi, Clash Display, and the rest of the Studio OS set.
